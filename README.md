# Analysis-of-the-carbon-footprint-of-abalone-aquaculture
We provide the detailed analysis of paper "From Industrial Emitter to Ecological Sink: Reconfiguring Global Abalone Aquaculture for a Net–Zero Carbon Future".
In the file of "Analysis in SI", we provide the calculation processes (including data and codes) and results in supplementary Information. Specifically, it covers abalone aquaculture production prediction, uncertainty of carbon sink of macroalgae,and the production change of abalone under different temperatures.
In the file of "figures in manuscript", we provide the counting processes (indcluding data and codes) and results of the figures in the manuscript. Among them, the code files of R language are graphic files, while the python files are calculation files.
